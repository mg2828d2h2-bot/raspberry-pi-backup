Privacy Policy

Application: Raspberry Pi Backup

Purpose

Raspberry Pi Backup is a personal-use application that uses rclone to transfer encrypted Raspberry Pi configuration backups to the owner’s Google Drive account.

Google Drive Access

The application requests Google Drive access solely to create, retrieve, manage, and delete backup files.

Data Collection and Storage

The application does not collect information for advertising, analytics, or commercial purposes.

Backup files are encrypted locally before being uploaded to Google Drive.

Google OAuth credentials are stored locally on the owner’s Raspberry Pi and are not published on this website.

Data Sharing

The application does not intentionally share backup contents with third parties. Encrypted backup files are stored in the owner’s Google Drive account.

Data Retention

The application retains backup files according to the owner’s configured retention policy. The owner can delete these files or revoke Google Drive access at any time.

Contact

This application is maintained for personal use. Questions about its data practices can be directed to the repository owner through GitHub.
